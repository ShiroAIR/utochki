# Уточки

## Играть на ПК
1. Скачай лаунчер: **[Utochki-Launcher.exe](https://github.com/ShiroAIR/utochki/releases/download/launcher/Utochki-Launcher.exe)**
2. Запусти его и нажми **«УСТАНОВИТЬ»** — он сам скачает игру и сделает ярлык «Уточки» на рабочем столе.
3. Дальше просто открывай лаунчер: он сам обновляет игру и себя.

Windows может предупредить («Windows защитила ваш компьютер») — нажми «Подробнее» → «Выполнить в любом случае»: лаунчер не подписан платным сертификатом.

## Играть на телефоне (Android)
Скачай **[Utochki.apk](https://github.com/ShiroAIR/utochki/releases/latest/download/Utochki.apk)** на телефон и установи (разреши установку из неизвестных источников). Новые версии игра предложит сама при запуске.

## Вместе
ПК и телефоны играют вместе по одному Wi-Fi или через точку доступа: хост — «Мультиплеер → Создать игру», друзья — «Подключиться» с его адресом.
